# Projeto de Física com Interface Gráfica

Este projeto é uma aplicação de física interativa desenvolvida em Python, com interface gráfica utilizando **Tkinter**. O projeto implementa simulações e visualizações de conceitos físicos, utilizando gráficos dinâmicos e animações. A visualização dos resultados é feita por meio de gráficos gerados com a biblioteca **Matplotlib**, enquanto cálculos e integrações são realizados com **NumPy** e **scipy.integrate**.

## Funcionalidades

### **Cálculos Quânticos**
- O sistema realiza cálculos baseados na mecânica quântica, como a energia de uma partícula confinada em uma caixa de potencial.


### **Interface Gráfica com Tkinter**
- A interface gráfica permite que o usuário interaja com o programa, ajustando parâmetros de simulação e visualizando os resultados em tempo real.
- O usuário pode ajustar variáveis como velocidade inicial, aceleração e outras constantes de acordo com o fenômeno em simulação.

### **Gráficos Dinâmicos**
- Utilizando **Matplotlib**, os resultados das simulações são exibidos em gráficos interativos.
- Gráficos atualizados em tempo real mostram a evolução do fenômeno físico, como a posição de uma partícula ao longo do tempo.

### **Animações**
- O projeto inclui animações interativas para visualizar o movimento de partículas e o comportamento dos sistemas físicos em função do tempo.
- As animações ajudam a ilustrar conceitos como o movimento acelerado, queda livre e outros fenômenos.

### **Integração Numérica**
- Utilização de **scipy.integrate** para resolver equações diferenciais numéricas que modelam fenômenos físicos.
- As equações de movimento e outras equações diferenciais são integradas para gerar trajetórias e comportamentos ao longo do tempo.

## Tecnologias Usadas

- **Tkinter**: Biblioteca para criação da interface gráfica.
- **Matplotlib**: Usada para a geração de gráficos e animações.
- **NumPy**: Utilizado para cálculos matemáticos e manipulação de arrays.
- **scipy.integrate**: Biblioteca para resolução de equações diferenciais numéricas.
